# Проверка знакомств, прочтения и нагрузки — 2026-11-06

## Автоматические проверки

- `go test ./... -count=1` и `go vet ./...` — успешно.
  Интеграционные тесты запускались с `TEST_DATABASE_URL` в отдельном временном
  PostgreSQL 18 на localhost. Рабочая Neon не использовалась.
- Проверены профиль и серверные ограничения, доступ без профиля только к чатам,
  отсутствие себя/неполных профилей среди кандидатов, повтор отклонения,
  возврат карточки через 7 дней, повторное использование диалога, параллельные
  встречные первые лайки и повторные лайки, одно системное сообщение.
- Проверены непрочитанное у обоих, исключение собственных сообщений,
  запрет чужих переписок и чужого ID сообщения, монотонный курсор,
  уведомления обоих участников о прочтении.
- Отдельная база была подготовлена миграциями 001–007 с двумя существующими
  пользователями и текстовым сообщением. После 008 оба пользователя и сообщение
  сохранились, миграция зарегистрирована один раз; весь набор Go-тестов прошёл.
- `npm test` — 37 тестов, все успешны. Включены общая подписка Pusher,
  завершение подписок при выходе, восстановление после таймаута конфигурации,
  отсутствие опроса звонков при рабочей подписке, резервный опрос после разрыва,
  требования видимости/фокуса для прочтения и отмена подтверждения при уходе.
- `npm run build`, `npm run lint` — успешно.

## Проверка интерфейса

Chrome headless, два независимых аккаунта/контекста, локальная API и временная
PostgreSQL. Проверены заполнение профиля через форму, входной запрет знакомств,
карточка, входящий лайк, подробности, принятие, совпадение, системное сообщение,
сохранение непрочитанного отдельно у обоих и появление двух галочек после чтения.
Проверены ширины 1440×1000 и 390×844, просмотрены снимки карточек.
При проверке возврата в окно событие фокуса воспроизводилось явно: headless
контексты не всегда генерируют его при `bringToFront`.

Локальный Pusher в браузерной проверке был выключен; для получения истории
использовалась кнопка обновления, а подписки/события проверены отдельными тестами.
Живая доставка через pusher.com и сценарий на двух физических устройствах
в этой задаче не подтверждены. Аудио/видео на устройствах заново не проверялись.

## Ограничение старого скрипта

`client/scripts/verify-visual-contract.mjs` привязан к старому коммиту и задаче
по дизайну/медиа: запрещает новые файлы API и изменение прежних эффектов.
Он завершается на разрешённых текущей задачей изменениях API. Это не проверка
работоспособности знакомств; скрипт сохранён без ослабления его условий.

Изменения подготовлены локально; размещение API/клиента и миграция рабочей Neon
в рамках этой проверки не выполнялись.
