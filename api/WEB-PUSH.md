# Web Push и установка приложения

Код подготовлен для Vercel + Render. Production в этой задаче не обновлялся.

## Настройка Render перед проверкой доставки

Локально из api запустить `go run ./cmd/pushkeys`. Сохранить обе переменные в защищённых Environment-настройках сервиса Render:
- VAPID_PUBLIC_KEY
- VAPID_PRIVATE_KEY

Приватный ключ не коммитить, не пересылать в чат и не менять на каждом деплое. Команда выводит секрет только тому, кто её запускает. При смене ключа устройства потребуется подключить заново.

Без этих переменных API сообщает enabled=false, а интерфейс объясняет, что уведомления пока не настроены. Генератор в ходе автоматических проверок с реальными ключами не запускался.

Сервер сохраняет подписки с привязкой к сессии. Выход и сброс пароля удаляют соответствующие сессии и подписки. В базе хранится очередь с уникальностью по устройству/сообщению; повтор сообщения не создаёт повторную задачу. Ошибки повторяются ограниченно, 404/410 удаляют подписку. Очередь ограничена на устройство. Превью и отключённые чаты передаются из существующих настроек. Читаемый активный чат учитывается короткой отметкой активности устройства.

В Настройках нажать «Включить на этом устройстве». Разрешение браузера запрашивается только этим действием. На iPhone потребуется установленное веб-приложение и поддерживаемая версия Safari/iOS. Реальную доставку и разрешения на физических устройствах проверить отдельно.

## PWA

Manifest: /manifest.webmanifest. Worker: /sw.js. Offline: /offline.html. Worker кэширует только публичные статические ресурсы; API и HTML авторизованной страницы не кэшируются. Обновление ожидает действия в настройках.

Подготовлены PNG 192/512, maskable и apple-touch-icon 180 из существующего SVG-логотипа. Установку на реальных устройствах ещё нужно проверить. Инструмент @resvg/resvg-js использован только для подготовки статических файлов и не добавлен в зависимости приложения.

## Публикация

Нужен согласованный релиз клиента и API: миграции 031–037 добавляют приватность, запросы, жалобы, роли групп и push. Миграция 036 меняет связь авторства группового сообщения, сохраняя историю при выходе участника. API запускает миграции автоматически при старте. Перед push в master, который запускает Render, требуется подтверждение production-релиза и резервная копия БД у владельца инфраструктуры.

Источником протокола служит библиотека https://github.com/SherClockHolmes/webpush-go ; зависимости зафиксированы в go.mod/go.sum. Новые зависимости: webpush-go 1.4.0 и golang-jwt/jwt/v5 5.3.1.
